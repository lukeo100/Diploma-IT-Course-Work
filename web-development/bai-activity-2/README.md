# Form Validation Activities

A series of progressive JavaScript activities teaching form validation basics.

## Activities

### [Activity 1: Display User Input](activity-1/)
**Difficulty:** Beginner

Learn the basics of DOM manipulation by displaying user input on the page.

**You will learn:**
- Getting elements with `getElementById`
- Reading input values with `.value`
- Setting text with `.innerText`
- Handling form submission

---

### [Activity 2: Login Form Validation](activity-2/)
**Difficulty:** Easy

Validate a login form with two fields. Check that both fields are filled in.

**You will learn:**
- Validating form fields
- Showing and hiding error messages
- Handling blur events
- Preventing default form submission

---

### [Activity 3: Registration Form Validation](activity-3/)
**Difficulty:** Intermediate

Validate a registration form with four fields and complex validation rules.

**You will learn:**
- Multiple validation rules per field
- Regular expressions for pattern matching
- Matching fields (password confirmation)
- Conditional error messages

## Getting Started

1. Fork this repository to your own GitHub account
2. Clone your fork to your computer
3. Open the activity folder you want to complete
4. Read the instructions in the markdown file
5. Open `script.js` and follow the steps
6. Open `index.html` in a browser to test your code (or use the **LivePreview** extension)
