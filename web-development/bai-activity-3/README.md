# Browser Storage: Arrays, Local Storage, and Cookies

This repository contains learning material and hands-on activities that introduce JavaScript arrays and two browser storage tools:

- **Arrays**: lists of values used to hold data in JavaScript.
- **Local Storage**: saving data in the browser for the user's convenience.
- **Cookies**: small pieces of data sent to the server, often used for logins and sessions.

By the end of the material, you will be able to:

- Work with JavaScript arrays: create, read, update, add, and remove items.
- Save, read, update, and delete items with Local Storage.
- Set, read, and delete cookies.
- Explain the difference between Local Storage and Cookies.
- Build persistent web apps that remember data.

## How to use this repository

1. **Read** through the files in order (01 to 06).
2. **Fork** this repository, then **clone** your fork to your computer.
3. **Complete** the hands-on activities in [activity-1.md](activity-1.md), [activity-2.md](activity-2.md), and [activity-3.md](activity-3.md).
4. **Push** your finished work back to your fork.
